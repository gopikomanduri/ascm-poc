# 🔥 FORGE Logo Files

## Logo Variants

### 1. **forge_logo_primary.svg**
- **Use for:** Main branding, documents, presentations
- **Size:** Scalable (1:1 square)
- **Best at:** Any size (64x64 to 1000x1000)
- **Background:** Transparent
- **Files:** Primary logo with white background

### 2. **forge_logo_social_square.svg**
- **Use for:** LinkedIn profile picture, Twitter avatar, Discord icon
- **Size:** 1:1 square
- **Best at:** 200x200 to 400x400
- **Background:** Dark navy (#0f172a)
- **Purpose:** Social media optimized with built-in background

### 3. **forge_logo_favicon.svg**
- **Use for:** Website favicon, browser tab icon, small UI elements
- **Size:** 1:1 square
- **Best at:** 32x32 to 64x64
- **Background:** Transparent
- **Purpose:** Simplified version for small display sizes

### 4. **forge_logo_banner.svg**
- **Use for:** LinkedIn banner, website headers, cover images
- **Size:** 4:1 wide rectangle (1200x300)
- **Best at:** Full size (1200x300) or scaled proportionally
- **Background:** Dark gradient
- **Purpose:** Includes logo + text for profile/header use

## 📱 LinkedIn Setup Guide

### Profile Picture
Use: **forge_logo_social_square.svg**
- Resolution: 400x400 px
- Format: PNG (convert from SVG)

### Banner Image
Use: **forge_logo_banner.svg**
- Resolution: 1200x300 px
- Format: PNG or JPG (convert from SVG)

### Favicon (Website)
Use: **forge_logo_favicon.svg**
- Resolution: 32x32 or 64x64 px
- Add to website: `<link rel="icon" href="favicon.svg">`

---

## 🔄 Converting SVG to PNG/JPG

If you need PNG/JPG versions, use an online converter or:

```bash
# Using imagemagick (if installed)
convert -background transparent forge_logo_primary.svg -density 300 forge_logo_primary.png

# Or use online tools:
# https://cloudconvert.com/svg-to-png
# https://convertio.co/svg-png/
```

## ✨ Logo Usage Guide

### Do's ✅
- Use primary logo on light backgrounds
- Use social square on social media
- Use banner for LinkedIn header
- Scale proportionally
- Maintain clear space around logo

### Don'ts ❌
- Don't modify colors without approval
- Don't squeeze or stretch logo
- Don't place on competing colors without contrast
- Don't rotate or flip the logo

## 📋 Specifications

### Primary Logo
- **Viewbox:** 0 0 200 200
- **Proportions:** 1:1 square
- **Elements:** Anvil, hammer, sparks, code accent, glow

### Social Square
- **Viewbox:** 0 0 200 200
- **Background:** Dark navy (#0f172a)
- **Safe area:** Center 160x160

### Favicon
- **Viewbox:** 0 0 64 64
- **Simplified:** Reduced detail for tiny sizes
- **Legible:** Works well at 32x32

### Banner
- **Viewbox:** 0 0 1200 300
- **Proportions:** 4:1 (16:4)
- **Layout:** Logo left, text right
