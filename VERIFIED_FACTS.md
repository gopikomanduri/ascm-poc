# Verified Facts (the ONLY claims GTM content may cite)

Edit this file with facts you can prove. Everything else generated by the GTM agents is treated as unverified.

- ASCM coordinates five (5 agents) AI agents (Product, Architect, Coder, Critic, Security) to change multiple repositories in one sprint, with a human approval gate before any commit.
- The Critic uses a different model from the Coder.
- ASCM runs locally; supports Gemini, OpenAI-compatible APIs, Anthropic and Ollama (offline).
- A path sandbox stops agents writing outside the allowed repo paths; a PII scrubber and audit log are built in.
- The project's own test suite passed in full on 2026-10-22 (see CI for the current count). It includes an end-to-end test of the orchestrator on two temporary git repos with a stubbed LLM; it does not exercise real model output.
- MR-Bench is a task set plus a repository-readiness heuristic; it does not run agents, so its score (37.5/100 on 2026-09-25) is not an agent result and is not comparable to other benchmarks. No live-agent multi-repo benchmark has been run yet.
- Status: early-stage proof of concept. Some agents (SRE, APM, on-call, Temporal workflows) are scaffolds.
- The probability models in tools/ascm_math_proofs.py use assumed inputs; their outputs are not measured defect-reduction results.
- Writing, committing and outreach require explicit human authorization; a run with `--yes` alone does not authorize a commit.
