# Fund Data Pipeline: Mutual Funds SLM Ingestion & Portfolio Analytics Engine

## Capability Contract
- **Archetype**: Provider
- **Language**: Python 3.11+
- **Allowed Paths**:
  - `app/fund_data.py`
  - `app/portfolio_analytics.py`
  - `app/main.py`
  - `tests/test_fund_data.py`
  - `tests/test_portfolio_analytics.py`

## Domain Primitives
- Mutual Fund Scheme Information Document (SID) and Key Information Memorandum (KIM) ingestion
- Net Asset Value (NAV) timeseries tracking and return calculation (CAGR, Rolling Returns)
- Risk-adjusted return analytics: Sharpe Ratio, Treynor Ratio, Alpha, Beta, Tracking Error
- Category benchmarks: Large Cap, Mid Cap, Small Cap, Flexi Cap, Liquid, Debt
- Vector chunking pipeline for RAG context feeding the Small Language Model (SLM)
