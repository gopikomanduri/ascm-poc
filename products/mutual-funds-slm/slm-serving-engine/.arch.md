# SLM Serving Engine: Mutual Funds Specialized Small Language Model Inference & Guardrails API

## Capability Contract
- **Archetype**: Consumer / Serving Gateway
- **Language**: Python 3.11+
- **Allowed Paths**:
  - `app/slm_serving.py`
  - `app/guardrails.py`
  - `app/main.py`
  - `tests/test_slm_serving.py`
  - `tests/test_guardrails.py`

## Domain Primitives
- High-throughput quantized Small Language Model (SLM) inference endpoint (e.g., Qwen2.5-1.5B / Phi-4-mini / Llama-3.2-3B)
- Financial advisory disclaimer injection (SEBI / SEC statutory compliance guardrails)
- Fund comparison prompt orchestrator and Fact Sheet summarization
- Deterministic hallucination validator (verifies NAV, Expense Ratio, and AUM against factual data-pipeline values)
- Sub-50ms local latency for fund managers and retail investor apps
